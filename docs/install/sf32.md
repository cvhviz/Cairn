# Installing on the LilyGO T-Display SF32 (coming soon)

> **Coming soon.** Cairn for the T-Display SF32 is in development and isn't in a release yet. This page previews how installing will work, so you can get the tools ready. Exact file names will be added when the first build ships.

The T-Display SF32 uses a **SiFli SF32LB52**, not an nRF52 or ESP32, so it installs with SiFli's own tool, `sftool`, over the board's USB serial port. There is no UF2 drive and no web flasher.

## What you'll need

- **sftool 0.2.5 or newer**, SiFli's open-source flashing tool. Older versions, such as the 0.1.7 that the SiFli SDK installs, lack some commands.
- A USB-C data cable. The board's only USB interface is a **CH343** USB-serial chip.
- **Windows:** install the WCH **CH343** driver first. macOS and Linux have it built in (the port shows as `/dev/cu.wchusbserial…` or `/dev/ttyACM…`).

## The files

A release will carry a zip with three files for the board and a flash script that runs the command below. The three files go at three addresses:

| Part | Address |
|---|---|
| bootloader | `0x12010000` |
| main image | `0x12020000` |
| flash table (ftab) | `0x12000000` |

## Writing them

All three go in one command, at 500 kbaud with compatibility mode on:

```bash
sftool -c SF32LB52 -p <port> -b 500000 --compat true write_flash \
  <bootloader>.bin@0x12010000 <main>.bin@0x12020000 <ftab>.bin@0x12000000
```

`<port>` is the CH343 serial port, for example `/dev/cu.wchusbserial1410` on macOS or `COM5` on Windows.

## Recovery

The SF32's ROM download mode is always reachable over USB, so a bad write can't brick the board. Run the same command again. Going back to LilyGO's factory firmware is also an `sftool write_flash` of their image.
